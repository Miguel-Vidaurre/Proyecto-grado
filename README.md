Sistema Web de Gestión para Taller Mecánico

Plataforma web desarrollada para digitalizar y optimizar la gestión administrativa del taller Mecatrónica Vedia, reemplazando procesos manuales por un sistema moderno, escalable y eficiente.

Sobre el proyecto

Este proyecto fue desarrollado como trabajo de grado en Ingeniería Informática, con el objetivo de resolver problemas reales de gestión en talleres mecánicos.

El sistema permite centralizar la información operativa del negocio, mejorar la toma de decisiones y aumentar la productividad mediante una solución web completa.

Problema

El taller operaba con procesos manuales, lo que generaba:

Registro lento de clientes y vehículos
Falta de control sobre servicios realizados
Baja eficiencia operativa
Mala experiencia del cliente
Solución

Se desarrolló un sistema web que:

Digitaliza todos los procesos administrativos
Centraliza la información en una base de datos
Permite acceso rápido y seguro a la información
Mejora la trazabilidad de servicios
Funcionalidades clave
Autenticación y control de acceso (roles)
Gestión de empleados
Gestión de clientes
Gestión de vehículos
Gestión de servicios
Cotizaciones
Inventario de repuestos
Compras y proveedores
Reportes administrativos
Historial de servicios
Arquitectura

Arquitectura basada en cliente-servidor (SPA + API REST):

Frontend (React)  →  API REST (Spring Boot)  →  PostgreSQL
Frontend: React + Material UI
Backend: Spring Boot (Java)
Base de datos: PostgreSQL

Stack tecnológico
Tecnología	Uso
React.js	Interfaz de usuario
Spring Boot	Backend / API REST
PostgreSQL	Base de datos
Material UI	UI/UX
Node.js	Entorno frontend
Postman	Testing de API
UML	Diseño del sistema
RUP	Metodología de desarrollo

Impacto del proyecto
Mejora en la organización del taller
Reducción de tiempos en procesos administrativos
Centralización de la información
Disminución de errores manuales
Base escalable para crecimiento del negocio

Metodología
El proyecto fue desarrollado bajo RUP (Rational Unified Process), permitiendo una estructura iterativa y controlada en cada fase del desarrollo.

Limitaciones
No incluye facturación electrónica (integración SIAT)
No contempla gestión contable (salarios)
